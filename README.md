# فهرس البطاقات الوطنية

تطبيق Windows بسيط لتسجيل اسم صاحب البطاقة ورقم البطاقة الوطنية فقط.

## الوظائف
- إضافة سريعة باستخدام Enter: الاسم ثم الرقم ثم الحفظ.
- تعديل وحذف مع تأكيد الحذف.
- بحث فوري بالاسم أو الرقم وترتيب أبجدي.
- منع تكرار رقم البطاقة.
- استيراد وتصدير CSV متوافق مع Excel.
- معاينة وطباعة القائمة.
- إنشاء نسخة احتياطية مستقلة لقاعدة البيانات.
- SQLite محلية؛ تبقى البيانات محفوظة عند تحديث ملف EXE.

## مكان البيانات
`%LOCALAPPDATA%\\CardArchive\\Archive.db`
