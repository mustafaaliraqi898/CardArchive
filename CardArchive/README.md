# CardArchive — WPF
تطبيق Windows عربي لإدارة فهرس أسماء أصحاب البطاقات الوطنية وأرقامها.
- WPF / .NET 10 / SQLite
- إضافة وتعديل وحذف وبحث فوري.
- منع تكرار رقم البطاقة.
- استيراد وتصدير CSV المتوافق مع Excel.
- طباعة القائمة والنسخ الاحتياطي.
- قاعدة البيانات محفوظة في `%LOCALAPPDATA%\CardArchive\Archive.db` وتبقى مستقلة عن تحديث البرنامج.
- واجهة RTL مع وضع نهاري وليلي.
